# AssistEd

Android app that helps sensory-impaired students learn independently

## The Problem
Many students with hearing or vision impairments depend on online tools . AssistEd brings key accessibility features together in one app 
## Features
- **Voice Navigation:** control the app by speaking
- **Live Captioning:** speech converted to text in real time
- **OCR:** read text from images using the camera
- **Auto Notes with Subject Tagging:** notes saved and organized by subject
- **Emergency SOS:** send an alert SMS in one tap
- **Noise Filter:** reduces background noise

## Tech Stack
Kotlin | MVVM | ML Kit | CameraX | Room Database | SpeechRecognizer API | SmsManager

## How to Run
1. Clone the repo: `git clone https://github.com/Vishaliii19/AssistEd.git`
2. Open it in Android Studio
3. Use JDK 17 and sync Gradle
4. Run on an emulator or Android device
